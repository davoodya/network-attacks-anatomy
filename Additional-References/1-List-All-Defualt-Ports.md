### All Default Ports - Ports with Details
در اینجا یک لیست جامع و مرجع از پورت‌های پیش‌فرض سرویس‌ها، پروتکل‌ها و اپلیکیشن‌های رایج در شبکه‌های کامپیوتری، سیستم‌عامل‌های ویندوز و لینوکس، دیتابیس‌ها و وب تهیه شده است. این لیست با فرمت درخواستی شما (لیست عددی با جزئیات) آماده شده تا به راحتی در Obsidian یا سایر ابزارهای یادداشت‌برداری کپی و استفاده شود.

توجه داشته باشید که برخی پورت‌ها ممکن است همزمان در هر دو پروتکل TCP و UDP استفاده شوند (مانند DNS یا SNMP)، که در بخش نوع پروتکل ذکر شده است.

1. **20 - TCP**:
    1. سرویس: FTP-Data
    2. توضیح مختصر: انتقال داده‌های فایل (پورت داده FTP)
    3. محل استفاده: تمام
    4. نوع پروتکل: TCP

2. **21 - TCP**:
    1. سرویس: FTP
    2. توضیح مختصر: کنترل اتصال فایل سرور، انتقال داده
    3. محل استفاده: تمام
    4. نوع پروتکل: TCP

3. **22 - TCP**:
    1. سرویس: SSH
    2. توضیح مختصر: دسترسی امن از راه دور به خط فرمان
    3. محل استفاده: Linux, Web
    4. نوع پروتکل: TCP

4. **23 - TCP**:
    1. سرویس: Telnet
    2. توضیح مختصر: دسترسی از راه دور غیرامن (متنی)
    3. محل استفاده: تمام
    4. نوع پروتکل: TCP

5. **25 - TCP**:
    1. سرویس: SMTP
    2. توضیح مختصر: ارسال ایمیل
    3. محل استفاده: Web, Linux, Windows
    4. نوع پروتکل: TCP

6. **53 - TCP/UDP**:
    1. سرویس: DNS
    2. توضیح مختصر: سیستم نام‌گذاری دامنه، تبدیل نام به IP
    3. محل استفاده: تمام
    4. نوع پروتکل: TCP/UDP

7. **67 - UDP**:
    1. سرویس: DHCP-Server
    2. توضیح مختصر: پیکربندی خودکار آدرس IP برای کلاینت‌ها
    3. محل استفاده: شبکه, Windows, Linux
    4. نوع پروتکل: UDP

8. **68 - UDP**:
    1. سرویس: DHCP-Client
    2. توضیح مختصر: دریافت پیکربندی از سرور DHCP
    3. محل استفاده: تمام
    4. نوع پروتکل: UDP

9. **69 - UDP**:
    1. سرویس: TFTP
    2. توضیح مختصر: انتقال فایل ساده و سبک (معمولاً برای بوت شبکه)
    3. محل استفاده: شبکه, Linux, Windows
    4. نوع پروتکل: UDP

10. **80 - TCP**:
    1. سرویس: HTTP
    2. توضیح مختصر: پروتکل انتقال ابرمتن، وب‌سرور غیرامن

    4. نوع پروتکل: TCP

11. **110 - TCP**:

    4. نوع پروتکل: TCP

12. **119 - TCP**:
