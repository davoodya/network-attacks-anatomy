## درباره کتاب

این کتاب به زبان فارسی نوشته شده و تلاش می‌کنه دنیای حملات شبکه رو از پایه باز کنه. از اینکه یک حمله چطور شکل می‌گیره، چه ابزارهایی پشتش هست، چه مکانیزمی داره، تا اینکه چطور می‌شه جلوش رو گرفت.

هدف این بوده که هم جنبه آموزشی داشته باشه و هم جنبه عملی. برای همین علاوه بر توضیح مفاهیم، اسکریپت‌های واقعی هم برای حملات شبکه آورده شده تا خواننده بتونه مفاهیم رو به‌صورت دست‌اول تجربه کنه. اسکریپت های داخل کتاب به زبان Python با کتابخانه Scapy نوشته شده.


### داخل کتاب چی هست؟

- معرفی انواع حملات شبکه
- ابزارهای رایج در حملات
- مکانیزم و نحوه کار حملات
- روش‌های دفاع و مقابله
- اسکریپت‌های عملی برای درک بهتر حملات

### برای کی مناسبه؟
این کتاب به نحوی نوشته شده که هم برای تازه واردان دنیای امنیت سایبری مناسب باشه و هم برای متخصصان این حوزه

مثلا در بخش حمله ARP Spoofing ابتدا پروتکل ARP و چگونگی کار این پروتکل توضیح داده شده، سپس به سراغ روش های پیاده سازی و ابزارهای مورد نیاز برای اینکار رفتیم و در آخر اسکریپت Python Scapy برای پیاده سازی حمله رو آوردیم. 
این مکانیزم باعث شده که بخش های ابتدایی مناسب همه باشه و بخش های پایانی مناسب متخصصان.

## About the Book

This book is written in Farsi and takes a hands-on approach to network attacks. It starts from the basics — how an attack takes shape, what tools are behind it, how the underlying mechanisms work — and walks through defense strategies as well.

The goal was to keep it both educational and practical. That's why alongside the theory, there are real scripts for network attacks so readers can actually try things out instead of just reading about them.

### What's Inside

- An overview of different network attacks
- Common tools used in attacks
- Attack mechanisms and how they actually work
- Defense methods and countermeasures
- Practical scripts for hands-on learning

### Who Is This For?

If you're just getting into network security, or even if you have some experience and want to revisit the fundamentals from a different angle, this book should be useful.

For instance, in the section on ARP spoofing attacks, we begin by explaining the ARP protocol and its mechanics; we then move on to implementation methods and the necessary tools, finally presenting a Python Scapy script to execute the attack.
This approach ensures that the introductory sections are suitable for everyone, while the concluding sections cater to specialists.
